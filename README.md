


🧬 Skill Genome

An AI-powered, bias-free talent evaluation and growth platform that goes beyond resumes.

Skill Genome is a futuristic AI-driven interview and skill analysis system that evaluates candidates holistically using resume analysis, GitHub/code assessment, real-time AI interviews, body language analysis, eye contact detection, and communication feedback. The goal is to map a candidate’s true skill DNA and provide a personalized growth roadmap.

⸻

🚀 Vision

Traditional hiring focuses too much on resumes and college names. Skill Genome changes the game by evaluating:
	•	📄 What you claim → Resume
	•	💻 What you built → GitHub & Projects
	•	🎤 How you perform → AI-powered live interview

This ensures fair, skill-first, bias-free hiring.

⸻

✨ Key Features

1️⃣ AI Interview Engine (Core Feature)
	•	Real-time webcam-based interview
	•	AI asks adaptive technical & behavioral questions
	•	Tracks:
	•	Eye contact 👀
	•	Facial expressions 🙂😐🙁
	•	Body posture 🧍
	•	Hand movements ✋
	•	Uses MediaPipe Holistic for landmark detection
	•	Generates communication & confidence scores

⸻

2️⃣ Body Language & Eye Contact Analysis
	•	Eye gaze tracking to measure engagement
	•	Head pose estimation
	•	Confidence detection via posture & facial cues
	•	Detects nervous patterns (frequent face touch, looking away, slouching)

⸻

3️⃣ Communication Skill Evaluation
	•	Speech clarity & fluency analysis
	•	Filler word detection (“uh”, “um”, “like”)
	•	Speaking pace & pauses
	•	Confidence score
	•	Personalized improvement tips

⸻

4️⃣ Resume + GitHub Skill Verification
	•	Resume parsing using NLP
	•	GitHub profile analysis:
	•	Project count
	•	Tech stack detection
	•	Code consistency
	•	Compares claimed skills vs actual work

⸻

5️⃣ Skill Genome Report (🔥 USP)

Each candidate receives a Skill Genome Map:
	•	Technical Skills 🧠
	•	Communication 💬
	•	Confidence 😎
	•	Problem Solving 🧩
	•	Consistency ⏱️
	•	Learning Ability 📈

Displayed as:
	•	Radar chart
	•	Skill heatmap
	•	Strength & weakness summary

⸻

6️⃣ Bias-Free Evaluation
	•	No college name bias
	•	No appearance-based judgment
	•	Focuses only on:
	•	Performance
	•	Skills
	•	Improvement trajectory

⸻

7️⃣ Personalized Growth Roadmap
	•	Custom learning path
	•	Communication exercises
	•	Mock interview feedback
	•	Suggested projects & topics

🧠 Tech Stack

Frontend
	•	HTML, CSS, JavaScript
	•	Webcam & microphone access
	•	Real-time UI feedback

Backend
	•	Node.js
	•	Express.js
	•	WebSockets (real-time interview)
	•	PostgreSQL (user & interview data)

AI / ML
	•	MediaPipe Holistic (Body, Face, Hands, Eyes)
	•	OpenCV
	•	Python (ML processing server)
	•	NLP for resume & speech analysis

⸻

🔄 System Architecture
	1.	User logs in
	2.	Resume + GitHub parsed
	3.	AI Interview starts (Webcam + Mic)
	4.	MediaPipe analyzes body language
	5.	NLP evaluates communication
	6.	Scores aggregated
	7.	Skill Genome generated
	8.	Growth roadmap suggested

⸻

🧪 ML Models Used
	•	MediaPipe Holistic (Google)
	•	Eye gaze estimation model
	•	Facial expression classifier
	•	Speech-to-text model
	•	Confidence scoring model

# Run ML server
cd ml
python app.py
